# Release Decision: Proof-Carrying Migration (v1.0-Beta)

## Demonstrable Capabilities
- Full end-to-end "Proof-Carrying Migration" lifecycle.
- Cryptographically verifiable receipts using ML-DSA-87.
- Rejection of all common adversarial attack vectors (tampering, substitution, replay).

## Evaluation Offering
**Bounded Evaluation (Paid)**:
The system is ready for a bounded evaluation with a partner bank. This evaluation can validate the *mechanism* of trust and the *lifecycle* of the passport using synthetic assets.

## Blockers for Production
- Lack of independent third-party cryptographic certification.
- Need for production-grade Key Management Systems (KMS).

## Final Verdict
**Ready for Bounded Evaluation.** Not ready for general production deployment.
