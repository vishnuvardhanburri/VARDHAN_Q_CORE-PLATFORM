## 3. Blockers to General Production Deployment

While the platform is fully verified for **single-node bounded evaluations (Discovery and Proof of Value)**, general multi-node production deployment requires closure of three external owner-action gates:

1. **Gate G1 (Independent Security Assurance):** Formal third-party penetration test and SOC 2 / ISO 27001 assessment must be commissioned and accepted. (Preparation packet ready in `docs/G1_ASSURANCE_PACKET.md`).
2. **Gate G3 (Enterprise Public Key Infrastructure):** Customer-managed root CA provisioning for multi-node mutual TLS certificate rotation. (Single-node mTLS proven).
3. **Gate G4 (Production Hardware Security Module):** Customer-managed PKCS#11 FIPS 140-3 Level 3 HSM or high-availability HashiCorp Vault cluster for master KEK wrapping. (Software transit drill proven).
