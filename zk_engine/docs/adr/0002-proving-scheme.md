# ADR-0002 — Proving Scheme: circom 2 + Groth16

**Status:** Accepted (pending approval)
**Date:** 2026-08-07

## Context
The system must produce proofs verifiable in Solidity with minimal on-chain cost, with a
healthy developer ecosystem and tooling we can pin for reproducibility.

## Decision
Use **circom 2** to author circuits and **snarkjs 0.7.x** for the Groth16 pipeline:

- Circuits → R1CS + WASM witness calculator.
- Groth16 trusted setup per circuit (phase 1 Powers of Tau + phase 2 zkey).
- Verifier contract generated by snarkjs (`Verifier.sol`), audited for our use.
- Fast witness generation via `circom_witnesscalc` (optional accelerator, fallback WASM).

## Consequences
- BN254 curve → EVM `ecpairing` precompile → ~200k gas verify, well within v1 budget.
- Per-circuit trusted setup required (see ADR-0003).
- Groth16 proofs are ~128 bytes on-chain, single pairing check in registry.

## Alternatives considered
- PLONK/Halo2 (no trusted setup): rejected — heavier on-chain verifier, weaker tooling
  maturity for the Ethereum path.
- Noir: capable but YAGNI; circom ecosystem better matches the Solidity verifier path.

## Future
Recursive aggregation (DEBT-3) evaluated post-v1; would switch engine internals only,
keeping the proof-format boundary stable.
